#botchattopic: Elixir chat + Go game + AWS queues, played by 42 AI botsupdated Nov 11, 2026

Build an AI bot chat network with microservices

A hands-on tutorial, from an empty folder to a hosted demo: an IRC-style chat where 42 bots talk in topic channels and play Guess the Number. One page per step, each with code you type yourself.

  • Elixir · Phoenix
  • Go · gRPC
  • Python · OpenRouter
  • SNS · SQS · Lambda
  • Terraform · Fly.io

What you'll build

Three services in three languages, talking over three kinds of connection:

  • Chat (Elixir/Phoenix) is the hub. Bots connect to it over a private WebSocket; visitors get a read-only, IRC-style viewer of every channel (#general, #python, #elixir, #golang, #startrek, #programming, #games).
  • Game (Go) runs Guess the Number in #games: 5 rounds per match, one guess per player per round, closest guess wins. It owns XP and levels.
  • Bots (Python) are 42 AI players spread across 4–5 cheap OpenRouter models. A director decides who speaks and when, so cost is fixed by config.
  • AWS carries events: a level-up goes through SNS → SQS → Lambda and comes back to chat as *** Pip has reached level 5!.

How to use this tutorial

Every step page has the same parts:

Part What it is
Learn first The concepts and official docs to read before you start.
Numbered sub-steps Small pieces, each with code and an explanation of why it looks that way.
Full code Setup and plumbing (config, Docker, Terraform, CI) is given in full: type it, read it, move on.
Exercise The core logic in Elixir, Go and Python is yours to write. You get the shape, a test, and hints you can open if stuck.
QA for this step Automated tests to have, manual checks, and one thing to break on purpose.
Checkpoint A check that proves the step works before you move on.

Budget about 3–5 months of evenings if you're new to all of it. Do the steps in order; each only relies on earlier ones. Five MVP milestones along the way each give you a working demo, so you can stop at any of them with something real to show, and every step has QA checks that feed the QA plan.

Using AI while you learn

Write the first version of every exercise yourself. Then ask AI to review it, explain an error, or compare your approach with idiomatic code. Let it write boilerplate you already understand, and read every line it writes before committing. Check its answers against the linked docs: libraries move fast.

The steps

Read the concepts primer first; it's short and every later page leans on it. Cards marked with an MVP badge are where a milestone is reached.

Part 1 · Foundations

  • Step 0 · 1 eveningTools and repo setupGit, Docker, mise, editor setup and the monorepo layout.
  • Step 1 · 1–2 weeksLearn Elixir basicsPattern matching, processes, a chat room as a GenServer, supervision and ExUnit.

Part 2 · The chat service

  • Step 2 · 1–2 weeksChat service in PhoenixTwo endpoints, revocable bot tokens, channels with topics, rate limits and channel tests.

Part 3 · Go and the game

  • Step 3 · 1 weekLearn Go basicsModules, interfaces, errors, goroutines with select, and table-driven tests.
  • Step 4 · 1–2 weeksGame service core in GoMatch rules as pure functions, table-driven tests, and a runner goroutine with timers.
  • Step 5 · 1 weekProtobuf and gRPCThe .proto contract, Buf codegen, a gRPC server with auth interceptors, and a fan-out hub.

Part 4 · Wiring it together

  • Step 6 · 1 weekMVP 1Connect chat to gameAn Elixir gRPC client, a self-healing stream bridge, and GameServ posting in #games.
  • Step 6b · 1 weekThe public viewerA read-only LiveView with channel tabs, colored nicks, a match status bar and countdown hooks.
  • Step 7 · 1–2 weeksMVP 2Python bot runner42 bots, OpenRouter, a director with per-channel rates, a daily budget, and game turns.

Part 5 · AWS and events

  • Step 8 · 1–2 eveningsAWS foundationsRoot lockdown, IAM Identity Center, CLI SSO, budgets, and a hands-on tour of SNS and SQS.
  • Step 9 · 1–2 weeks"Events: SNS, SQS and Broadway"XP in Postgres, a publisher interface, SNS fan-out, and an idempotent Broadway consumer.
  • Step 10 · 1 weekLambda announcer in GoA Go Lambda on provided.al2023, partial batch failures, and a notices queue chat pulls from.
  • Step 11 · 1 weekMVP 3Infrastructure as code with TerraformRemote state, a reusable fan-out queue module, the Lambda, and least-privilege IAM.

Part 6 · Ship it

  • Step 12 · 2–3 eveningsLocal dev with Docker ComposeDockerfiles for each service, a Compose file with health checks, and AWS options for local dev.
  • Step 13 · 1 weekMVP 4DeployThree Fly apps, private networking, secrets, migrations, and outside-in security checks.
  • Step 14 · 1–2 weeksMVP 5Observability and CIOpenTelemetry across three languages and a queue, plus one CI workflow per service.
