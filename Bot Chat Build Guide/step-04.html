Step 41–2 weeks

Game service core in Go

Write Guess the Number as a plain Go library with no network and no real clock, test it thoroughly, then wrap it in a goroutine that owns it.

Build the game as a library first. With no network and no real clock inside, every rule can be tested in milliseconds, and the network layer in Step 5 becomes a thin wrapper.

The rules: a match has 5 rounds. Players type !join during a 20 s lobby. Each round has a new secret number from 1–100 and every player guesses exactly once, in a turn order that rotates each round, with 15 s per turn. Each guess gets "higher" or "lower". An exact hit ends the round at once; otherwise the closest guess wins, and ties go to whoever guessed first. Most round wins takes the match.

Learn first

  • The idea behind this step: Functional core, imperative shell.
  • math/rand/v2: you'll inject a seeded generator so tests are repeatable.
  • Timer.Reset and the Go 1.23 timer changes that make Reset safe to call without draining the channel.

cd game

4.2 Types and the constructor (full code)

The match never does anything; it returns effects describing what should happen ("say this", "start a 15 s timer", "a round was won"). The runner carries them out.

internal/match/match.go
// Package match holds the rules of Guess the Number.
// It never sleeps, reads the clock, or does I/O: the runner does those.
package match

import (
    "errors"
    "fmt"
    "math/rand/v2"
    "slices"
    "strconv"
    "strings"
    "time"
)

type Phase int

const (
    Lobby Phase = iota
    TurnActive
    Reveal
    Intermission
    Over
)

type PlayerID string

// Effect describes something that should happen. The runner carries it out.
type Effect interface{ effect() }

type Say struct{ Text string }
type StartTimer struct{ After time.Duration }
type RoundWon struct {
    Player   PlayerID
    Round    int
    Exact    bool
    Distance int
}
type MatchWon struct {
    Player    PlayerID
    RoundWins int
}

func (Say) effect()        {}
func (StartTimer) effect() {}
func (RoundWon) effect()   {}
func (MatchWon) effect()   {}

type Config struct {
    Rounds                     int
    Lo, Hi                     int
    MinPlayers                 int
    JoinWindow, Turn           time.Duration
    RevealPause, Intermission time.Duration
}

func DefaultConfig() Config {
    return Config{
        Rounds: 5, Lo: 1, Hi: 100, MinPlayers: 2,
        JoinWindow: 20 * time.Second, Turn: 15 * time.Second,
        RevealPause: 5 * time.Second, Intermission: 10 * time.Second,
    }
}

type guess struct{ value, order int }

type Match struct {
    cfg       Config
    rng       *rand.Rand
    Phase     Phase
    Round     int
    Secret    int
    Lo, Hi    int // range still possible, from higher/lower feedback
    Players   []PlayerID
    Order     []PlayerID
    TurnIdx   int
    Guesses   map[PlayerID]guess
    RoundWins map[PlayerID]int
}

func New(cfg Config, rng *rand.Rand) (*Match, []Effect) {
    m := &Match{cfg: cfg, rng: rng, Phase: Lobby, RoundWins: map[PlayerID]int{}}
    return m, []Effect{
        Say{fmt.Sprintf("New match of Guess the Number! Type !join in the next %s.", cfg.JoinWindow)},
        StartTimer{cfg.JoinWindow},
    }
}

Also move your ParseGuess from Step 3 into this package:

var ErrOutOfRange = errors.New("out of range")

// ParseGuess accepts a whole number between lo and hi, surrounded by optional spaces.
func ParseGuess(text string, lo, hi int) (int, error) {
    n, err := strconv.Atoi(strings.TrimSpace(text))
    if err != nil {
        return 0, fmt.Errorf("not a number %q: %w", text, err)
    }
    if n < lo || n > hi {
        return 0, ErrOutOfRange
    }
    return n, nil
}

4.3 The two entry points

State only changes through two methods: an input arrives, or a timer fires. Here's HandleInput in full; it just routes by phase.

func (m *Match) HandleInput(p PlayerID, text string) []Effect {
    text = strings.TrimSpace(text)
    switch m.Phase {
    case Lobby:
        if text == "!join" {
            return m.join(p)
        }
    case TurnActive:
        return m.handleGuess(p, text)
    }
    return nil
}

Exercise: joining

Write join(p PlayerID) []Effect. A player can join once; a second !join from the same player does nothing. Reply with a Say like pip joined (2 players).

Solution 
func (m *Match) join(p PlayerID) []Effect {
    if slices.Contains(m.Players, p) {
        return nil
    }
    m.Players = append(m.Players, p)
    return []Effect{Say{fmt.Sprintf("%s joined (%d players).", p, len(m.Players))}}
}

4.4 Starting a round and prompting turns

Exercise: startRound and promptTurn

startRound() should: increment Round; pick Secret with m.rng.IntN; reset Lo/Hi to the config range; clear Guesses; set TurnIdx to 0 and Phase to TurnActive; then announce the round and the turn order, followed by promptTurn().

promptTurn() says whose turn it is and returns StartTimer{m.cfg.Turn} (put it first, so anything announcing the turn already knows the new deadline).

Hint: a random number in a range

rand.IntN(n) returns 0..n-1, so lo + rng.IntN(hi-lo+1) gives lo..hi inclusive.

Solution 
func (m *Match) startRound() []Effect {
    m.Round++
    m.Secret = m.cfg.Lo + m.rng.IntN(m.cfg.Hi-m.cfg.Lo+1)
    m.Lo, m.Hi = m.cfg.Lo, m.cfg.Hi
    m.Guesses = map[PlayerID]guess{}
    m.TurnIdx = 0
    m.Phase = TurnActive
    names := make([]string, len(m.Order))
    for i, p := range m.Order {
        names[i] = string(p)
    }
    head := Say{fmt.Sprintf("Round %d of %d. I'm thinking of a number from %d-%d. Turn order: %s.",
        m.Round, m.cfg.Rounds, m.cfg.Lo, m.cfg.Hi, strings.Join(names, ", "))}
    return append([]Effect{head}, m.promptTurn()...)
}

func (m *Match) promptTurn() []Effect {
    p := m.Order[m.TurnIdx]
    return []Effect{
        StartTimer{m.cfg.Turn}, // first, so the prompt carries the new deadline
        Say{fmt.Sprintf("%s, you're up (%s).", p, m.cfg.Turn)},
    }
}

4.5 Handling a guess

This is the heart of the game. Write it test-first: the table below describes what should happen, and your code makes it pass.

internal/match/match_test.go
package match

import (
    "math/rand/v2"
    "testing"
    "time"
)

func testConfig(rounds int) Config {
    return Config{Rounds: rounds, Lo: 1, Hi: 100, MinPlayers: 2,
        JoinWindow: time.Second, Turn: time.Second, RevealPause: time.Second, Intermission: time.Second}
}

// started returns a match in round 1 with the given players and a forced secret.
func started(t *testing.T, rounds, secret int, players ...PlayerID) *Match {
    t.Helper()
    m, _ := New(testConfig(rounds), rand.New(rand.NewPCG(1, 2)))
    for _, p := range players {
        m.HandleInput(p, "!join")
    }
    m.HandleTimeout() // lobby closes, round 1 starts
    m.Secret = secret
    return m
}

func find[T Effect](effects []Effect) (T, bool) {
    for _, e := range effects {
        if v, ok := e.(T); ok {
            return v, true
        }
    }
    var zero T
    return zero, false
}

func TestInputRules(t *testing.T) {
    cases := []struct {
        name    string
        who     int // index into Order
        text    string
        wantTurn int
    }{
        {"out of turn is ignored", 1, "50", 0},
        {"chatter is ignored", 0, "hello", 0},
        {"out of range does not use the turn", 0, "500", 0},
        {"valid guess passes the turn", 0, "50", 1},
    }
    for _, tc := range cases {
        t.Run(tc.name, func(t *testing.T) {
            m := started(t, 1, 40, "pip", "vex")
            m.HandleInput(m.Order[tc.who], tc.text)
            if m.TurnIdx != tc.wantTurn {
                t.Fatalf("turn = %d, want %d", m.TurnIdx, tc.wantTurn)
            }
        })
    }
}

Exercise: handleGuess and advanceTurn

handleGuess(p, text) must:

  1. Ignore anyone whose turn it isn't.
  2. Ignore text that isn't a number (bots chat during games).
  3. Reply with the valid range for out-of-range numbers, without using up the turn.
  4. Record the guess with its order (len(m.Guesses)), so ties can be broken.
  5. End the round immediately on an exact hit.
  6. Otherwise say "Higher than N." or "Lower than N.", narrow Lo/Hi, and call advanceTurn().

advanceTurn() moves to the next player, or ends the round when everyone has guessed.

Hint: telling the two errors apart

errors.Is(err, ErrOutOfRange) is true only for the range error; any other non-nil error means "not a number".

Solution 
func (m *Match) handleGuess(p PlayerID, text string) []Effect {
    if p != m.Order[m.TurnIdx] {
        return nil // not your turn: ignore
    }
    n, err := ParseGuess(text, m.cfg.Lo, m.cfg.Hi)
    if errors.Is(err, ErrOutOfRange) {
        return []Effect{Say{fmt.Sprintf("%s, pick a number from %d-%d.", p, m.cfg.Lo, m.cfg.Hi)}}
    }
    if err != nil {
        return nil // chatter, not a guess
    }
    m.Guesses[p] = guess{value: n, order: len(m.Guesses)}
    if n == m.Secret {
        return m.endRound()
    }
    var hint string
    if n < m.Secret {
        hint = fmt.Sprintf("Higher than %d.", n)
        m.Lo = max(m.Lo, n+1)
    } else {
        hint = fmt.Sprintf("Lower than %d.", n)
        m.Hi = min(m.Hi, n-1)
    }
    return append([]Effect{Say{hint}}, m.advanceTurn()...)
}

func (m *Match) advanceTurn() []Effect {
    m.TurnIdx++
    if m.TurnIdx >= len(m.Order) {
        return m.endRound()
    }
    return m.promptTurn()
}

4.6 Ending a round

func TestClosestGuessWinsAndTiesGoToFirst(t *testing.T) {
    m := started(t, 1, 40, "pip", "vex")
    m.HandleInput(m.Order[0], "35")
    effects := m.HandleInput(m.Order[1], "45")
    won, ok := find[RoundWon](effects)
    if !ok || won.Player != m.Order[0] {
        t.Fatalf("expected %s to win the tie, got %+v", m.Order[0], won)
    }
}

Exercise: closest and endRound

closest() returns the winner, their distance from the secret, and whether anyone guessed at all. Smallest distance wins; on a tie, the lower order (earlier guess) wins.

endRound() sets Phase to Reveal, increments the winner's RoundWins, says the result, emits RoundWon (with Exact set when the distance is 0), and starts the reveal pause. If nobody guessed, it just reveals the number.

Hint: iterating a map

Map iteration order in Go is random on purpose. That's why the tie-break uses the stored order, never the position in the loop.

Solution 
func (m *Match) closest() (PlayerID, int, bool) {
    var best PlayerID
    bestDist, bestOrder, found := 0, 0, false
    for p, g := range m.Guesses {
        d := g.value - m.Secret
        if d < 0 {
            d = -d
        }
        if !found || d < bestDist || (d == bestDist && g.order < bestOrder) {
            best, bestDist, bestOrder, found = p, d, g.order, true
        }
    }
    return best, bestDist, found
}

func (m *Match) endRound() []Effect {
    m.Phase = Reveal
    winner, dist, ok := m.closest()
    if !ok {
        return []Effect{
            Say{fmt.Sprintf("Nobody guessed. The number was %d.", m.Secret)},
            StartTimer{m.cfg.RevealPause},
        }
    }
    m.RoundWins[winner]++
    msg := fmt.Sprintf("The number was %d! %s was closest (off by %d).", m.Secret, winner, dist)
    if dist == 0 {
        msg = fmt.Sprintf("%s got it exactly: %d!", winner, m.Secret)
    }
    return []Effect{
        Say{msg},
        RoundWon{Player: winner, Round: m.Round, Exact: dist == 0, Distance: dist},
        StartTimer{m.cfg.RevealPause},
    }
}

4.7 Timeouts move the match forward

Every phase except Over ends with a timer. HandleTimeout decides what happens next.

Exercise: HandleTimeout and endMatch

Write a switch m.Phase with one case per phase:

Phase when the timer fires What happens
Lobby Fewer than MinPlayers? End the match. Otherwise copy Players into Order and start round 1.
TurnActive The current player ran out of time; say so and advanceTurn().
Reveal Last round? endMatch(). Otherwise announce the intermission and start its timer.
Intermission Rotate Order (first player moves to the back) and start the next round.

endMatch() sets Over, finds the player with the most round wins (earliest joiner wins ties) and emits MatchWon.

Hint: rotating a slice safely

append(m.Order[1:], m.Order[0]) can write into the slice's shared backing array. append(slices.Clone(m.Order[1:]), m.Order[0]) can't.

Solution 
func (m *Match) HandleTimeout() []Effect {
    switch m.Phase {
    case Lobby:
        if len(m.Players) < m.cfg.MinPlayers {
            m.Phase = Over
            return []Effect{Say{"Not enough players joined. Type !start to try again."}}
        }
        m.Order = slices.Clone(m.Players)
        return m.startRound()
    case TurnActive:
        p := m.Order[m.TurnIdx]
        return append([]Effect{Say{fmt.Sprintf("%s ran out of time.", p)}}, m.advanceTurn()...)
    case Reveal:
        if m.Round >= m.cfg.Rounds {
            return m.endMatch()
        }
        m.Phase = Intermission
        return []Effect{
            Say{fmt.Sprintf("Round %d starts in %s...", m.Round+1, m.cfg.Intermission)},
            StartTimer{m.cfg.Intermission},
        }
    case Intermission:
        m.Order = append(slices.Clone(m.Order[1:]), m.Order[0]) // rotate who goes first
        return m.startRound()
    }
    return nil
}

func (m *Match) endMatch() []Effect {
    m.Phase = Over
    var best PlayerID
    bestWins := 0
    for _, p := range m.Players { // Players order breaks ties: earliest joiner wins
        if w := m.RoundWins[p]; w > bestWins {
            best, bestWins = p, w
        }
    }
    if bestWins == 0 {
        return []Effect{Say{"Match over! Nobody won a round."}}
    }
    return []Effect{
        Say{fmt.Sprintf("Match over! %s wins with %d rounds.", best, bestWins)},
        MatchWon{Player: best, RoundWins: bestWins},
    }
}

4.8 The runner: one goroutine owns the match (full code)

The runner is the "imperative shell". It holds the only reference to a *Match, feeds it inputs and timer ticks, resets its timer on StartTimer, and hands every effect to an out callback (timer starts included, so viewers can show a countdown). Nothing else may touch the match, so there are no locks.

internal/runner/runner.go
// Package runner owns one match per channel and turns its effects into real actions.
package runner

import (
    "context"
    "time"

    "github.com/you/botchat/game/internal/match"
)

type Input struct {
    Player match.PlayerID
    Text   string
    MsgID  string
}

// Runner is the only goroutine allowed to touch its Match.
type Runner struct {
    Inputs chan Input
    out    func(match.Effect)
    m      *match.Match
}

func New(m *match.Match, out func(match.Effect)) *Runner {
    return &Runner{Inputs: make(chan Input, 64), out: out, m: m}
}

// Run blocks until the match is over or ctx is cancelled.
func (r *Runner) Run(ctx context.Context, initial []match.Effect) {
    timer := time.NewTimer(time.Hour)
    timer.Stop()
    defer timer.Stop()

    seen := map[string]bool{} // msg IDs already handled (idempotency)

    apply := func(effects []match.Effect) {
        for _, e := range effects {
            if st, ok := e.(match.StartTimer); ok {
                timer.Reset(st.After) // Go 1.23+: Reset also drains a pending tick
            }
            r.out(e) // StartTimer too, so viewers can show a countdown
        }
    }

    apply(initial)
    for r.m.Phase != match.Over {
        select {
        case <-ctx.Done():
            return
        case in := <-r.Inputs:
            if in.MsgID != "" {
                if seen[in.MsgID] {
                    continue
                }
                seen[in.MsgID] = true
            }
            apply(r.m.HandleInput(in.Player, in.Text))
        case <-timer.C:
            apply(r.m.HandleTimeout())
        }
    }
}

The seen map makes inputs idempotent: if chat retries a request with the same message ID, the guess counts once.

internal/runner/runner_test.go
package runner

import (
    "context"
    "math/rand/v2"
    "testing"
    "time"

    "github.com/you/botchat/game/internal/match"
)

func TestRunnerPlaysToTheEnd(t *testing.T) {
    cfg := match.Config{Rounds: 1, Lo: 1, Hi: 100, MinPlayers: 2,
        JoinWindow: 20 * time.Millisecond, Turn: 20 * time.Millisecond,
        RevealPause: 10 * time.Millisecond, Intermission: 10 * time.Millisecond}
    m, initial := match.New(cfg, rand.New(rand.NewPCG(1, 2)))
    var said []string
    r := New(m, func(e match.Effect) {
        if s, ok := e.(match.Say); ok {
            said = append(said, s.Text)
        }
    })
    r.Inputs <- Input{Player: "pip", Text: "!join", MsgID: "1"}
    r.Inputs <- Input{Player: "vex", Text: "!join", MsgID: "2"}
    r.Inputs <- Input{Player: "vex", Text: "!join", MsgID: "2"} // duplicate delivery

    ctx, cancel := context.WithTimeout(context.Background(), 2*time.Second)
    defer cancel()
    r.Run(ctx, initial) // nobody guesses: turns time out, match ends
    if m.Phase != match.Over {
        t.Fatalf("match did not finish; said: %v", said)
    }
}
