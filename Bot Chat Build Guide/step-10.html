Step 101 week

Lambda announcer in Go

A Go Lambda turns level-up events into "*** pip has reached level 5!" notices and queues them for chat, which pulls them. Nothing in AWS calls into chat.

A Go Lambda reads the announcements queue (a second SNS subscriber), formats a notice, and sends it to a chat-notices queue. Chat pulls from that queue with Broadway, exactly like Step 9. Because chat only ever pulls, it needs no inbound API and no secret shared with AWS.

Learn first

  • Building Lambda functions with Go: Go runs on the OS-only provided.al2023 runtime; the old go1.x runtime is gone.
  • Deploying Go with .zip archives: a Linux binary named bootstrap.
  • Using Lambda with SQS and handling errors / partial batch responses.
  • aws-lambda-go (lambda and events packages).

10.1 How SQS triggers a Lambda

AWS polls the queue for you and invokes your function with a batch of up to 10 messages. If the function returns an error, every message in the batch becomes visible again and is retried. With ReportBatchItemFailures turned on, you return just the IDs that failed, and only those are retried. After maxReceiveCount failures a message moves to the dead-letter queue.

cd lambdas/announcer

10.3 Make the handler testable

The handler's only side effect is sending to SQS. Hide that behind a one-method interface, so tests can pass a fake.

main.go types and wiring, full code
package main

import (
    "context"
    "encoding/json"
    "fmt"
    "log/slog"
    "os"

    "github.com/aws/aws-lambda-go/events"
    "github.com/aws/aws-lambda-go/lambda"
    "github.com/aws/aws-sdk-go-v2/aws"
    "github.com/aws/aws-sdk-go-v2/config"
    "github.com/aws/aws-sdk-go-v2/service/sqs"
)

type LevelUp struct {
    PlayerID string `json:"player_id"`
    NewLevel int    `json:"new_level"`
}

type Notice struct {
    Room      string `json:"room"`
    Text      string `json:"text"`
    DedupeKey string `json:"dedupe_key"`
}

// Sender is the slice of the SQS client this function uses.
type Sender interface {
    SendMessage(ctx context.Context, in *sqs.SendMessageInput, opts ...func(*sqs.Options)) (*sqs.SendMessageOutput, error)
}

type Handler struct {
    SQS      Sender
    QueueURL string
}

func main() {
    cfg, err := config.LoadDefaultConfig(context.Background())
    if err != nil {
        slog.Error("aws config", "err", err)
        os.Exit(1)
    }
    h := &Handler{SQS: sqs.NewFromConfig(cfg), QueueURL: os.Getenv("CHAT_NOTICES_QUEUE_URL")}
    lambda.Start(h.Handle)
}

The real *sqs.Client already has a SendMessage method with exactly that signature, so it satisfies Sender without any adapter.

10.4 The handler

Exercise: Handle with partial batch failures

Write func (h *Handler) Handle(ctx context.Context, ev events.SQSEvent) (events.SQSEventResponse, error):

  1. For each record, unmarshal the body into LevelUp. If that fails, log it and skip it (retrying malformed JSON won't help).
  2. Build a Notice for room games with text *** <player> has reached level <n>! and dedupe key levelup:<player>:<n>.
  3. Send it to h.QueueURL. If sending fails, add the record's MessageId to BatchItemFailures.
  4. Return the response and a nil error, so only the failed items are retried.
Hint: the response type

events.SQSEventResponse{BatchItemFailures: []events.SQSBatchItemFailure{{ItemIdentifier: rec.MessageId}}}. An empty BatchItemFailures means "all succeeded".

Solution 
func (h *Handler) Handle(ctx context.Context, ev events.SQSEvent) (events.SQSEventResponse, error) {
    var failed []events.SQSBatchItemFailure
    for _, rec := range ev.Records {
        var e LevelUp
        if err := json.Unmarshal([]byte(rec.Body), &e); err != nil || e.PlayerID == "" {
            slog.Warn("skipping malformed record", "id", rec.MessageId, "err", err)
            continue
        }
        body, _ := json.Marshal(Notice{
            Room:      "games",
            Text:      fmt.Sprintf("*** %s has reached level %d!", e.PlayerID, e.NewLevel),
            DedupeKey: fmt.Sprintf("levelup:%s:%d", e.PlayerID, e.NewLevel),
        })
        if _, err := h.SQS.SendMessage(ctx, &sqs.SendMessageInput{
            QueueUrl:    aws.String(h.QueueURL),
            MessageBody: aws.String(string(body)),
        }); err != nil {
            slog.Error("send notice", "id", rec.MessageId, "err", err)
            failed = append(failed, events.SQSBatchItemFailure{ItemIdentifier: rec.MessageId})
        }
    }
    return events.SQSEventResponse{BatchItemFailures: failed}, nil
}

10.5 Test it with a fake sender (full code)

main_test.go
package main

import (
    "context"
    "errors"
    "strings"
    "testing"

    "github.com/aws/aws-lambda-go/events"
    "github.com/aws/aws-sdk-go-v2/service/sqs"
)

type fakeSQS struct {
    sent []string
    fail bool
}

func (f *fakeSQS) SendMessage(_ context.Context, in *sqs.SendMessageInput, _ ...func(*sqs.Options)) (*sqs.SendMessageOutput, error) {
    if f.fail {
        return nil, errors.New("boom")
    }
    f.sent = append(f.sent, *in.MessageBody)
    return &sqs.SendMessageOutput{}, nil
}

func TestHandle(t *testing.T) {
    ev := events.SQSEvent{Records: []events.SQSMessage{
        {MessageId: "1", Body: `{"player_id":"pip","new_level":5}`},
        {MessageId: "2", Body: `not json`},
    }}

    ok := &fakeSQS{}
    resp, err := (&Handler{SQS: ok, QueueURL: "q"}).Handle(context.Background(), ev)
    if err != nil || len(resp.BatchItemFailures) != 0 || len(ok.sent) != 1 {
        t.Fatalf("want 1 sent, 0 failures; got %d sent, %+v, %v", len(ok.sent), resp, err)
    }
    if !strings.Contains(ok.sent[0], "pip has reached level 5") {
        t.Fatalf("unexpected notice: %s", ok.sent[0])
    }

    bad := &fakeSQS{fail: true}
    resp, _ = (&Handler{SQS: bad, QueueURL: "q"}).Handle(context.Background(), ev)
    if len(resp.BatchItemFailures) != 1 || resp.BatchItemFailures[0].ItemIdentifier != "1" {
        t.Fatalf("want only record 1 reported as failed, got %+v", resp)
    }
}

10.6 Build the deployment package (full code)

GOOS=linux GOARCH=arm64 CGO_ENABLED=0 go build -tags lambda.norpc -o bootstrap .
zip function.zip bootstrap

arm64 runs on Graviton, which is cheaper per millisecond. -tags lambda.norpc drops an RPC mode the provided.al2023 runtime doesn't use. Terraform deploys the zip in Step 11.

10.7 The chat side

Exercise: Chat.NoticeConsumer

Copy Chat.LevelConsumer from Step 9 into Chat.NoticeConsumer reading NOTICES_QUEUE_URL. For each message, insert {dedupe_key, room, text} into a notices table with a unique index on dedupe_key. If the insert succeeds, post the text to the room as GameServ with Chat.Rooms.post_message/3. If it fails on the unique constraint, the notice was already posted: just let Broadway ack the message.

Hint

Repo.insert(changeset) returns {:error, changeset} on a unique violation when the changeset has unique_constraint(:dedupe_key). Match on that and return the message unchanged.
