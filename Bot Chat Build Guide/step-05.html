Step 51 week

Protobuf and gRPC

Define the chat-to-game contract in a .proto file, generate Go code with Buf, and serve it over gRPC behind a shared-secret check.

The .proto file is the contract between chat and game. Both sides generate code from it, so a mismatch becomes a compile error instead of a 3 a.m. bug.

Learn first

  • Protocol Buffers language guide (proto3).
  • gRPC core concepts: unary vs server-streaming RPCs, deadlines, status codes.
  • gRPC Go quick start and basics tutorial.
  • Buf CLI quickstart and the buf.gen.yaml v2 reference.
  • grpcurl: curl for gRPC.

5.1 Write the contract (full code)

proto/game/v1/game.proto
syntax = "proto3";

package game.v1;

option go_package = "github.com/<you>/botchat/game/gen/game/v1;gamev1";

service GameService {
  // Forward one chat line from #games. Returns as soon as it's queued.
  rpc SubmitInput(SubmitInputRequest) returns (SubmitInputResponse);
  // Stream everything GameServ says in a channel.
  rpc Subscribe(SubscribeRequest) returns (stream GameMessage);
  // Current XP and level, used to seed level badges.
  rpc GetPlayer(GetPlayerRequest) returns (GetPlayerResponse);
}

message SubmitInputRequest {
  string channel = 1;
  string player_id = 2;
  string text = 3;
  string msg_id = 4; // idempotency key: the same msg_id twice counts once
}
message SubmitInputResponse {}

message SubscribeRequest {
  string channel = 1;
}
message GameMessage {
  string channel = 1;
  string text = 2;
  int64 seq = 3; // +1 per message per channel; a gap means messages were missed
}

message GetPlayerRequest {
  string player_id = 1;
}
message GetPlayerResponse {
  string player_id = 1;
  int32 level = 2;
  int64 xp = 3;
}

Field numbers, not names, are what go over the wire. Never reuse or renumber one; that's the rule buf breaking enforces.

5.3 The hub: channels, matches and subscribers

The gRPC handlers need somewhere to send inputs and somewhere to read GameServ's lines from. The hub maps each chat channel to its running match and its subscribers. It uses a mutex, because it's a lookup table shared by many request goroutines. The match itself is still owned by its runner goroutine alone.

Exercise: write the hub

Write internal/hub with four methods:

  • Submit(channel, input): if no match is running and the text is !start, start one; if a match is running, send the input to its runner without blocking.
  • Subscribe(channel) (<-chan *gamev1.GameMessage, func()): register a buffered Go channel and return it plus a function that unregisters it.
  • broadcast(channel, text): increment the channel's seq, build a GameMessage, and send it to every subscriber without blocking; a slow subscriber misses messages and sees a gap in seq.
  • handleEffect(channel, effect): the runner's out callback. For now, only match.Say does anything.

Write a test that subscribes, submits !start, and receives a message with seq == 1.

Hint: never block while holding the lock

Copy what you need (like st.runner) while holding h.mu, unlock, then send to the runner. Sending on a full channel while holding a mutex is how deadlocks start. Inside broadcast, select with a default: case makes each send non-blocking.

Solution 
// Package hub maps chat channels to running matches and fans GameServ's lines out to subscribers.
package hub

import (
    "context"
    "log/slog"
    "math/rand/v2"
    "strings"
    "sync"
    "time"

    gamev1 "github.com/<you>/botchat/game/gen/game/v1"
    "github.com/<you>/botchat/game/internal/match"
    "github.com/<you>/botchat/game/internal/runner"
)

type Hub struct {
    mu       sync.Mutex
    cfg      match.Config
    channels map[string]*channelState
}

type channelState struct {
    runner *runner.Runner // nil when no match is running
    subs   map[int]chan *gamev1.GameMessage
    nextID int
    seq    int64
}

func New(cfg match.Config) *Hub {
    return &Hub{cfg: cfg, channels: map[string]*channelState{}}
}

// state returns the channel's state, creating it on first use. Caller holds h.mu.
func (h *Hub) state(ch string) *channelState {
    st, ok := h.channels[ch]
    if !ok {
        st = &channelState{subs: map[int]chan *gamev1.GameMessage{}}
        h.channels[ch] = st
    }
    return st
}

// Submit routes one chat line to the channel's match, starting one on "!start".
func (h *Hub) Submit(ch string, in runner.Input) {
    h.mu.Lock()
    st := h.state(ch)
    if st.runner == nil {
        if strings.TrimSpace(in.Text) == "!start" {
            h.startMatch(ch, st)
        }
        h.mu.Unlock()
        return
    }
    r := st.runner
    h.mu.Unlock()

    select {
    case r.Inputs <- in:
    default:
        slog.Warn("input dropped: runner busy", "channel", ch)
    }
}

// startMatch creates a match and runs it in its own goroutine. Caller holds h.mu.
func (h *Hub) startMatch(ch string, st *channelState) {
    seed := uint64(time.Now().UnixNano())
    m, initial := match.New(h.cfg, rand.New(rand.NewPCG(seed, seed>>1)))
    r := runner.New(m, func(e match.Effect) { h.handleEffect(ch, e) })
    st.runner = r
    go func() {
        r.Run(context.Background(), initial)
        h.mu.Lock()
        st.runner = nil
        h.mu.Unlock()
    }()
}

func (h *Hub) handleEffect(ch string, e match.Effect) {
    switch e := e.(type) {
    case match.Say:
        h.broadcast(ch, e.Text)
    case match.RoundWon, match.MatchWon:
        // Step 9: award XP and publish level-ups here.
    }
}

func (h *Hub) broadcast(ch, text string) {
    h.mu.Lock()
    defer h.mu.Unlock()
    st := h.state(ch)
    st.seq++
    msg := &gamev1.GameMessage{Channel: ch, Text: text, Seq: st.seq}
    for _, sub := range st.subs {
        select {
        case sub <- msg:
        default: // slow subscriber: drop; it will notice the seq gap
        }
    }
}

// Subscribe returns a stream of the channel's messages and a func to stop it.
func (h *Hub) Subscribe(ch string) (<-chan *gamev1.GameMessage, func()) {
    h.mu.Lock()
    defer h.mu.Unlock()
    st := h.state(ch)
    id := st.nextID
    st.nextID++
    c := make(chan *gamev1.GameMessage, 32)
    st.subs[id] = c
    return c, func() {
        h.mu.Lock()
        delete(st.subs, id)
        h.mu.Unlock()
    }
}

5.4 The gRPC server (full code)

Every call must carry an x-internal-token header matching GAME_INTERNAL_TOKEN. Interceptors check it once for all methods, unary and streaming.

cmd/server/main.go
package main

import (
    "context"
    "crypto/subtle"
    "log/slog"
    "net"
    "os"
    "os/signal"
    "syscall"

    "google.golang.org/grpc"
    "google.golang.org/grpc/codes"
    "google.golang.org/grpc/metadata"
    "google.golang.org/grpc/reflection"
    "google.golang.org/grpc/status"

    gamev1 "github.com/<you>/botchat/game/gen/game/v1"
    "github.com/<you>/botchat/game/internal/hub"
    "github.com/<you>/botchat/game/internal/match"
)

func checkToken(ctx context.Context, want string) error {
    md, _ := metadata.FromIncomingContext(ctx)
    got := md.Get("x-internal-token")
    if len(got) != 1 || subtle.ConstantTimeCompare([]byte(got[0]), []byte(want)) != 1 {
        return status.Error(codes.Unauthenticated, "missing or bad internal token")
    }
    return nil
}

func main() {
    token := os.Getenv("GAME_INTERNAL_TOKEN")
    if token == "" {
        slog.Error("GAME_INTERNAL_TOKEN is required")
        os.Exit(1)
    }

    unary := func(ctx context.Context, req any, _ *grpc.UnaryServerInfo, next grpc.UnaryHandler) (any, error) {
        if err := checkToken(ctx, token); err != nil {
            return nil, err
        }
        return next(ctx, req)
    }
    stream := func(srv any, ss grpc.ServerStream, _ *grpc.StreamServerInfo, next grpc.StreamHandler) error {
        if err := checkToken(ss.Context(), token); err != nil {
            return err
        }
        return next(srv, ss)
    }

    s := grpc.NewServer(grpc.UnaryInterceptor(unary), grpc.StreamInterceptor(stream))
    gamev1.RegisterGameServiceServer(s, &server{hub: hub.New(match.DefaultConfig())})
    reflection.Register(s) // lets grpcurl list methods (it still needs the token)

    lis, err := net.Listen("tcp", "[::]:50051") // [::] also accepts IPv4 locally
    if err != nil {
        slog.Error("listen", "err", err)
        os.Exit(1)
    }

    ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
    defer stop()
    go func() {
        <-ctx.Done()
        slog.Info("shutting down")
        s.GracefulStop()
    }()

    slog.Info("game listening", "addr", lis.Addr())
    if err := s.Serve(lis); err != nil {
        slog.Error("serve", "err", err)
    }
}

subtle.ConstantTimeCompare takes the same time whether the first byte or the last one differs, so an attacker can't guess the token one character at a time by timing responses.

5.5 The handlers

cmd/server/server.go
package main

import (
    "context"

    "google.golang.org/grpc"
    "google.golang.org/grpc/codes"
    "google.golang.org/grpc/status"

    gamev1 "github.com/<you>/botchat/game/gen/game/v1"
    "github.com/<you>/botchat/game/internal/hub"
    "github.com/<you>/botchat/game/internal/match"
    "github.com/<you>/botchat/game/internal/runner"
)

type server struct {
    gamev1.UnimplementedGameServiceServer // future methods return Unimplemented, not a crash
    hub *hub.Hub
}

func (s *server) SubmitInput(ctx context.Context, req *gamev1.SubmitInputRequest) (*gamev1.SubmitInputResponse, error) {
    if req.GetChannel() == "" || req.GetPlayerId() == "" {
        return nil, status.Error(codes.InvalidArgument, "channel and player_id are required")
    }
    s.hub.Submit(req.GetChannel(), runner.Input{
        Player: match.PlayerID(req.GetPlayerId()),
        Text:   req.GetText(),
        MsgID:  req.GetMsgId(),
    })
    return &gamev1.SubmitInputResponse{}, nil
}

Exercise: Subscribe

Implement Subscribe(req *gamev1.SubscribeRequest, stream grpc.ServerStreamingServer[gamev1.GameMessage]) error. Subscribe to the hub, unsubscribe when you return, and loop: send each message with stream.Send, and return nil when stream.Context().Done() fires (the client went away).

Recent versions of protoc-gen-go-grpc generate the generic grpc.ServerStreamingServer[T] type; older ones generate GameService_SubscribeServer. Use whichever your generated file declares.

Solution 
func (s *server) Subscribe(req *gamev1.SubscribeRequest, stream grpc.ServerStreamingServer[gamev1.GameMessage]) error {
    msgs, stop := s.hub.Subscribe(req.GetChannel())
    defer stop()
    for {
        select {
        case <-stream.Context().Done():
            return nil
        case msg := <-msgs:
            if err := stream.Send(msg); err != nil {
                return err
            }
        }
    }
}

5.7 Deadlines and status codes

Every gRPC call from chat will carry a deadline (2 s for SubmitInput). On the server, ctx is cancelled when that deadline passes, so long work should check ctx.Err(). Return errors with status.Error(code, msg) and pick the code by who's at fault:

Code Use it when
InvalidArgument The request is malformed (missing channel).
Unauthenticated Missing or wrong token.
NotFound GetPlayer for an unknown player.
Unavailable A dependency is down; the client may retry.
Internal A bug. Log it with details; send the client a short message.

Exercise: contract hygiene

Rename a field in game.proto and run buf breaking --against '.git#branch=main'. Read the error, then revert. Adding a new field with a new number passes; you'll do exactly that in Step 6b.

QA for this step

Automated

  • A hub test proving a slow subscriber (never reads) doesn't block other subscribers or the runner.
  • buf lint and buf breaking --against '.git#branch=main' pass.

Manual

  • grpcurl without x-internal-token returns Unauthenticated; without channel returns InvalidArgument.
  • Two grpcurl Subscribe streams on the same channel both receive every message with the same seq.

Break it on purpose

  • Kill a grpcurl subscriber with Ctrl-C mid-match: the server logs nothing alarming and the match continues.

Checkpoint

You can play a full match using only grpcurl, calls without the token fail with Unauthenticated, and buf lint and buf breaking both pass.
