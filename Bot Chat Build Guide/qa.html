QA plan

What to test, where, and when: the test pyramid for each service, two runnable tools (an end-to-end smoke test and a cost dry run), failure drills, and a release checklist.

File paths on this page are relative to the repo root (so bots/tests/smoke.py sits next to the bots service's pyproject.toml).

Quality here means three things: the game is fair and finishes, the bills stay small, and nothing private is reachable from outside. Every step page ends with a QA for this step box; this page collects the shared tools and the checks that span services.

Principles

  • A step isn't done until its tests are. The checkpoint at the end of each step includes them.
  • Test the core without the network. The match rules, the director and the budget are pure enough to test in milliseconds. That's why they're designed that way.
  • Fakes at the edges. A fake LLM, a log publisher instead of SNS, a fake SQS sender. Real services only in the smoke test and in production checks.
  • Every bug gets a test first. Reproduce it in a failing test, then fix it.

The test pyramid, per service

Level Chat (Elixir) Game (Go) Bots (Python) Lambda (Go)
Unit ExUnit for contexts, tokens, rate limiter Table tests for match rules, XP; fuzz ParseGuess pytest for director, budget, turns Handler with a fake sender
Integration Phoenix.ChannelTest, Phoenix.LiveViewTest, Ecto against a real Postgres Hub + runner with real timers (short); pgx store against Postgres Phoenix client against the fake chat aws lambda invoke with a sample event
Contract buf breaking on every pull request same Event JSON shape: one fixture file shared by publisher and consumers same fixture
End to end Smoke test: two test bots play a full match through the real stack Level-up shows a *** notice

What runs when

When What Time
On save Formatter, compiler warnings, linters Seconds
Before each commit Unit tests for the service you touched Under a minute
Every pull request (CI, Step 14) All unit + integration tests, buf breaking, terraform validate A few minutes

End-to-end smoke test

Two test bots, smoke_a and smoke_b, play one full match through the real chat, bridge and game. They always guess 50, so the match is quick and deterministic enough to check. Create both bots from IEx (Step 2) with games as their only channel, and keep their tokens with your other secrets.

bots/tests/smoke.py
"""End-to-end smoke test: two test bots play one full match through the real stack.

Usage:
    CHAT_URL=ws://localhost:4001 SMOKE_TOKEN_A=... SMOKE_TOKEN_B=... uv run python -m tests.smoke
Exit code 0 means pass. Create bots named smoke_a and smoke_b first (Step 2, admin from IEx).
"""
import asyncio
import os
import re
import sys

from bots.phx import PhoenixClient

TIMEOUT = float(os.environ.get("SMOKE_TIMEOUT", 8 * 60))  # 5 rounds with default timers: 3-5 min
ROUND_START = re.compile(r"^Round \d+ of \d+\.")


async def run(url: str, token_a: str, token_b: str) -> int:
    seen: list[str] = []
    done = asyncio.Event()
    clients: dict[str, PhoenixClient] = {}

    async def watch(topic, event, payload):
        """Only smoke_a's socket reacts, so each GameServ line is handled once."""
        if event != "new_msg" or payload.get("nick") != "GameServ":
            return
        text = payload["body"]
        seen.append(text)
        print("GameServ:", text, flush=True)
        for nick, client in clients.items():
            if text.startswith(f"{nick}, you're up"):
                await client.push("room:games", "new_msg", {"body": "50"})
        if text.startswith("Match over!") or text.startswith("Not enough players"):
            done.set()

    async def ignore(*_):
        pass

    clients["smoke_a"] = PhoenixClient(url, token_a, ["room:games"], watch)
    clients["smoke_b"] = PhoenixClient(url, token_b, ["room:games"], ignore)
    tasks = [asyncio.create_task(c.run_forever()) for c in clients.values()]
    a, b = clients["smoke_a"], clients["smoke_b"]
    try:
        await asyncio.sleep(2)                       # let both sockets connect and join
        await a.push("room:games", "new_msg", {"body": "!start"})
        await asyncio.sleep(2.5)                     # stay under the per-bot limit in #games
        await a.push("room:games", "new_msg", {"body": "!join"})
        await b.push("room:games", "new_msg", {"body": "!join"})
        await asyncio.wait_for(done.wait(), TIMEOUT)
    except TimeoutError:
        print("FAIL: the match did not finish in time", file=sys.stderr)
        return 1
    finally:
        for t in tasks:
            t.cancel()

    checks = {
        "lobby opened": any("!join" in s for s in seen),
        "5 rounds started": sum(bool(ROUND_START.match(s)) for s in seen) == 5,
        "both players prompted": all(any(s.startswith(f"{n}, you're up") for s in seen) for n in clients),
        "match ended with a winner": any(s.startswith("Match over!") and "wins" in s for s in seen),
    }
    for name, ok in checks.items():
        print(("PASS  " if ok else "FAIL  ") + name)
    return 0 if all(checks.values()) else 1


def main() -> None:
    url = os.environ.get("CHAT_URL", "ws://localhost:4001")
    sys.exit(asyncio.run(run(url, os.environ["SMOKE_TOKEN_A"], os.environ["SMOKE_TOKEN_B"])))


if __name__ == "__main__":
    main()

To test the smoke test itself (a tool you trust blindly is a liability), run it against a 40-line fake of chat and GameServ that speaks the same Phoenix protocol:

The fake chat server and its test
bots/tests/fake_chat.py
"""A tiny fake of chat + GameServ speaking Phoenix's V2 protocol, to test the smoke test itself."""
import asyncio
import json

from websockets.asyncio.server import serve


async def fake_chat(port: int, rounds: int = 5):
    conns = {}          # websocket -> nick (from the token)
    joins = []
    guesses = asyncio.Queue()

    async def send_all(text):
        for ws in list(conns):
            await ws.send(json.dumps(["1", None, "room:games", "new_msg", {"nick": "GameServ", "body": text}]))

    async def gameserv():
        await send_all("New match of Guess the Number! Type !join in the next 1s.")
        while len(joins) < 2:
            await asyncio.sleep(0.05)
        for r in range(1, rounds + 1):
            await send_all(f"Round {r} of {rounds}. I'm thinking of a number from 1-100.")
            for nick in joins:
                await send_all(f"{nick}, you're up (15s).")
                who, _ = await guesses.get()
                assert who == nick
            await send_all(f"The number was 50! {joins[0]} got it exactly: 50!")
        await send_all(f"Match over! {joins[0]} wins with {rounds} rounds.")

    async def handler(ws):
        nick = ws.request.path.split("token=")[1]
        conns[ws] = nick
        async for raw in ws:
            join_ref, ref, topic, event, payload = json.loads(raw)
            if event == "phx_join":
                await ws.send(json.dumps([join_ref, ref, topic, "phx_reply", {"status": "ok", "response": {}}]))
            elif event == "new_msg":
                body = payload["body"]
                if body == "!start":
                    asyncio.create_task(gameserv())
                elif body == "!join":
                    joins.append(nick)
                else:
                    await guesses.put((nick, body))

    return await serve(handler, "127.0.0.1", port)
bots/tests/test_smoke.py
import asyncio
from tests import smoke
from tests.fake_chat import fake_chat


async def test_smoke_passes_against_fake_chat(monkeypatch):
    server = await fake_chat(8765)
    sleeps = asyncio.sleep

    async def fast_sleep(s):          # skip the polite waits
        await sleeps(min(s, 0.05))
    monkeypatch.setattr(smoke.asyncio, "sleep", fast_sleep)
    try:
        code = await smoke.run("ws://127.0.0.1:8765", "smoke_a", "smoke_b")
    finally:
        server.close()
    assert code == 0

Cost dry run

Before you change config.toml or add bots, simulate a full day of the real director with fake LLM calls. Virtual time jumps from one wake-up to the next, so a day takes well under a second. It reports calls per channel against the configured limit and projected spend per model.

bots/prices.toml look up real prices on each model's OpenRouter page
"vendor-a/cheap-model" = { input = 0.10, output = 0.40 }   # USD per 1M tokens
"vendor-b/cheap-model" = { input = 0.15, output = 0.60 }
bots/tests/dry_run.py
"""Cost dry run: simulate one day of the real director with fake LLM calls, in about a second.

Usage:  uv run python -m tests.dry_run prices.toml
prices.toml maps each model in config.toml to its USD price per 1M input/output tokens.
"""
import asyncio
import heapq
import random
import sys
import tomllib
from collections import Counter
from datetime import datetime, timedelta, timezone
from pathlib import Path

from bots.budget import Budget
from bots.director import run_channel

DAY = 24 * 3600
TOKENS_IN, TOKENS_OUT = 850, 120     # per call: persona + 15 lines of history in, one line out


class VirtualTime:
    """Fake asyncio.sleep: time jumps straight to the next wake-up instead of waiting."""

    def __init__(self):
        self.now, self._heap, self._n = 0.0, [], 0

    async def sleep(self, seconds: float) -> None:
        fut = asyncio.get_running_loop().create_future()
        heapq.heappush(self._heap, (self.now + seconds, self._n, fut))
        self._n += 1
        await fut

    async def run_until(self, end: float) -> None:
        while True:
            for _ in range(10):              # let woken tasks run to their next sleep
                await asyncio.sleep(0)
            if not self._heap or self._heap[0][0] > end:
                return
            self.now, _, fut = heapq.heappop(self._heap)
            fut.set_result(None)


class SimBot:
    def __init__(self, nick, home, model, price, log):
        self.nick, self.home, self.model, self.price, self.log = nick, set(home), model, price, log

    async def speak(self, channel: str) -> float:
        cost = (TOKENS_IN * self.price["input"] + TOKENS_OUT * self.price["output"]) / 1_000_000
        self.log.append((channel, self.model, cost))
        return cost


async def simulate(config: dict, personas: list[dict], prices: dict) -> dict:
    vt = VirtualTime()
    start = datetime(2026, 1, 1, tzinfo=timezone.utc)
    budget = Budget(config["budget"]["daily_usd"], clock=lambda: start + timedelta(seconds=vt.now))
    budget.wait_for_reset = lambda: vt.sleep(budget.seconds_until_reset() + 1)

    models = [g["model"] for g in config["model_groups"] for _ in range(g["bots"])]
    log: list = []
    bots = [SimBot(p["nick"], p["home"], m, prices[m], log) for p, m in zip(personas, models)]
    rng = random.Random(7)
    tasks = [
        asyncio.create_task(run_channel(ch["name"], ch["per_hour"], [b for b in bots if ch["name"] in b.home],
                                        budget, lambda _c: [], rng=rng, sleep=vt.sleep))
        for ch in config["channels"]
    ]
    await vt.run_until(DAY)
    for t in tasks:
        t.cancel()
    return {
        "calls_per_channel": Counter(c for c, _, _ in log),
        "cost_per_model": {m: sum(x for _, mm, x in log if mm == m) for m in {m for _, m, _ in log}},
        "total_usd": sum(x for _, _, x in log),
    }


def main() -> None:
    root = Path(__file__).resolve().parents[1] / "bots"
    config = tomllib.loads((root / "config.toml").read_text())
    personas = tomllib.loads((root / "personas.toml").read_text())["bots"]
    prices = tomllib.loads(Path(sys.argv[1]).read_text())
    result = asyncio.run(simulate(config, personas, prices))
    limits = {c["name"]: c["per_hour"] * 24 for c in config["channels"]}
    print("channel        calls/day  limit")
    for ch, n in sorted(result["calls_per_channel"].items()):
        print(f"#{ch:<13} {n:>9}  {limits[ch]:>5}")
    for m, usd in sorted(result["cost_per_model"].items()):
        print(f"{m:<28} ${usd:7.3f}")
    print(f"total ${result['total_usd']:.3f} / budget ${config['budget']['daily_usd']:.2f}")


if __name__ == "__main__":
    main()

uv run python -m tests.dry_run prices.toml

With 42 bots, the sample config and the sample prices above, it prints about 360 calls per topic channel (480 in #general) and a projected total of about $0.36 a day. Calls land within a percent or two of per_hour × 24 because of the director's jitter; anything more than 5% over is a bug.

bots/tests/test_dry_run.py
from tests.dry_run import simulate

CONFIG = {
    "budget": {"daily_usd": 100.0},
    "channels": [{"name": "python", "per_hour": 12}, {"name": "games", "per_hour": 0}],
    "model_groups": [{"model": "a", "bots": 1}, {"model": "b", "bots": 1}],
}
PERSONAS = [{"nick": "pip", "home": ["python"]}, {"nick": "vex", "home": ["python"]}]
PRICES = {"a": {"input": 1.0, "output": 1.0}, "b": {"input": 1.0, "output": 1.0}}


async def test_rate_is_about_per_hour_times_24():
    r = await simulate(CONFIG, PERSONAS, PRICES)
    assert 12 * 24 * 0.85 <= r["calls_per_channel"]["python"] <= 12 * 24 * 1.15
    assert "games" not in r["calls_per_channel"]


async def test_budget_cuts_off_the_day():
    tight = {**CONFIG, "budget": {"daily_usd": 0.05}}   # each call costs ~$0.00097
    r = await simulate(tight, PERSONAS, PRICES)
    assert r["total_usd"] < 0.05 + 0.002
    assert r["calls_per_channel"]["python"] < 60

Manual checks for the viewer

  • Every channel tab loads without a full page reload; the URL changes.
  • On a phone (390 px wide): the channel list scrolls sideways, the nick list is hidden, the status bar fits.
  • A bot message containing <script>alert(1)</script> and **bold** shows exactly those characters.
  • A 400-character message without spaces wraps instead of widening the page.
  • With the network throttled to "Slow 3G" in DevTools, the page still loads and reconnects after you go offline for 10 s.
  • Lighthouse accessibility score is 90 or higher; channel links are reachable with Tab and show a focus ring.
  • The countdown never shows a negative number and disappears between turns.
  • The network panel shows only the LiveView socket and static assets: no requests to the bot socket.

ev '{"type":"player.leveled_up","version":1,"player_id":"pip","old_level":4,"new_level":5}'  # duplicate
ev '{"type":"player.leveled_up","version":1,"player_id":"pip","old_level":3,"new_level":4}'  # late, older
ev 'not json'                                                                                  # malformed
Event Expected
First pip's badge becomes Lv 5
Duplicate Nothing changes, no error
Older event, arriving late Badge stays Lv 5
Malformed Logged; after 5 receives it's in level-updates-dlq

Then empty the DLQ: aws sqs purge-queue --queue-url <dlq url>.

Chaos drills

Break one thing at a time, on purpose, and write down what happened.

Drill How Expected
Game dies mid-match fly machine restart on the game (or docker compose restart game) Bridge logs a seq gap and reconnects; the next !start works.
Chat restarts Restart chat All 42 bots reconnect within a minute, with jittered timing (not all in one second).
Bot token revoked Revoke one bot's token in IEx That bot disconnects and can't reconnect; the others don't notice.
LLM provider down Set an invalid OPENROUTER_API_KEY Chat goes quiet; game turns fall back to the midpoint guess; nothing crashes.
Budget exhausted Set daily_usd = 0.01 All bots pause within a call or two and resume after midnight UTC.
SQS credentials removed Unset chat's AWS secrets The consumer logs errors; chat keeps serving; badges catch up after you restore them.
Bad deploy Deploy a chat image that crashes on boot, then fly releases and fly deploy --image <previous> Rolled back in under 5 minutes.

Security checks

  • The outside-in table in Step 13, after every deploy.
  • Dependencies, monthly: mix hex.audit and mix_audit for chat, govulncheck ./... for game and Lambda, pip-audit for bots, and an image scanner such as Trivy for the Docker images.
  • Secrets: git log -p | grep -iE 'token|secret|sk-or-' finds nothing; or run gitleaks.

Release checklist

  • All CI workflows green on the commit you're deploying.
  • buf breaking passed; if the proto changed, deploy the game first, then chat.
  • Database migrations are backwards-compatible with the running version (add columns, don't rename).
  • Cost dry run re-run if config.toml, personas or models changed.
  • Smoke test passes against local Compose.
  • Deploy; smoke test passes against production.
  • Outside-in security checks pass.
  • Both DLQs empty 30 minutes after deploy.
  • git tag the release; note it in the changelog.
