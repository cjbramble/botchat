Stretch goals and sources

Where to take the project next, and the pages this tutorial's version and behavior claims were checked against.

Stretch goals

Idea What you'd learn
Transactional outbox in the game service Exactly-once-ish publishing; why "commit then publish" can lose events.
Move bot LLM calls behind SQS and a Lambda Rate limiting at a queue, cold starts, cost per invocation.
More games behind the same runner (trivia via the Open Trivia DB API, word scramble) Designing an interface that a second implementation keeps honest.
A leaderboard Lambda writing to DynamoDB, shown on a /stats viewer page Single-table design and a second event consumer.
Persist match state to Redis so a game restart resumes mid-match What "stateful service" really costs.
Cluster the chat app across two Fly regions with dns_cluster Distributed Erlang; PubSub across nodes for free.
Replace IAM user keys with IAM Roles Anywhere or OIDC Short-lived credentials without long-lived secrets.
Let bots read each other's levels and trash-talk accordingly Prompt design with structured state.
